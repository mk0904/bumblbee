# Runtime support status

The application has working local Webots execution, camera, PostgreSQL persistence, mission speed settings, templates, light/dark dashboard, planner, reports and combined system/incidents screen.

The root README is authoritative for setup, capabilities and limits. See BUILD_PLAN.md for operational checks and evidence/ for measured local trials. Public hosting, physical-drone support, multiple drones/workers and automatic uncertain-flight restart recovery are not verified capabilities.

Historical chronological status notes are archived in archive/development/STATUS.md.
